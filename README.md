# Fold Matrix — web test build

**Play:** https://ajaykumar-wq.github.io/fold-play/

Fold Matrix is an origami puzzle game: fold the paper along its creases to make the shape on the goal card.
This repository only hosts the **web test build** (5 worlds, 50 levels) so testers can play in a browser and send feedback.

- Works on phones and desktops (Chrome, Edge, Firefox, Safari). On a desktop, drag with the mouse.
- Progress is saved in your browser.

## Send feedback
Tap **Feedback** in the game (Home screen, or under the card after finishing a level), or use
**Send feedback** below the game. Both open a short form here with the level and version already filled in.
You need a free GitHub account to submit it.

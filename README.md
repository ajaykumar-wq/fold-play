# Fold Matrix — playtest

**Play:** https://ajaykumar-wq.github.io/fold-play/ (phones and desktops: Chrome, Edge, Firefox, Safari)
**Android test APK:** see the latest test release linked from the game's main repository (or ask the team).

Fold Matrix is an origami puzzle game: fold the paper along its creases to make the shape on the goal card.
This repository hosts the **web test build** (6 worlds, 60 levels, 6 surprise levels) and collects playtest feedback.

## How to playtest (about 20 minutes)
1. Open the play link (or install the test APK). Progress is saved on your device / in your browser.
2. Play from the start. **Finish at least 5 levels**: the first levels teach the folds.
3. Tap **Feedback** in the game (on Home, or under the result card). It unlocks after 5 levels and shows your
   progress until then. It opens a short form here with the level, version and device already filled in.
4. Answer the questions and add anything you noticed. Submitting needs a free GitHub account.

Feedback from fewer than 5 levels is closed automatically with a friendly note (play more, then edit and reopen).
Accepted reports get the **accepted** label.

## Privacy
The game sends nothing by itself. The form only contains what you submit, plus the level, version, screen size
and device model the game fills in. It is public on GitHub.
